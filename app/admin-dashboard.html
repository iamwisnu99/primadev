Pengaturan Payment Gateway

Pilih gateway aktif untuk memproses seluruh transaksi pembayaran lisensi.

Gateway Aktif
Panduan Konfigurasi Midtrans
1 Konfigurasi Notification URL di Midtrans Dashboard

Buka Midtrans Dashboard → Settings → Configuration → Payment Notification URL, isi dengan URL di bawah ini:

https://apps-primadev.netlify.app/.netlify/functions/webhook
2 Tambahkan Environment Variables di Netlify
MIDTRANS_SERVER_KEY Server Key dari Midtrans Dashboard (SB-Mid-server-... untuk sandbox)
MIDTRANS_CLIENT_KEY Client Key dari Midtrans Dashboard (SB-Mid-client-... untuk sandbox)
MIDTRANS_IS_PRODUCTION false untuk sandbox, true untuk production
Untuk Finish/Error/Unfinish Redirect URL di Midtrans Dashboard, isi dengan URL store Anda (e.g. https://apps-primadev.netlify.app/app/store). Webhook notifikasi server tetap dikirim ke Notification URL di atas.
Pengingat Konfigurasi Xendit
Pastikan XENDIT_SECRET_KEY dikonfigurasi di Netlify Environment Variables.
Pastikan XENDIT_CALLBACK_TOKEN dikonfigurasi dan dicocokkan di Xendit Dashboard → Settings → Developers → Callbacks.
Webhook URL Xendit (atur di Dashboard): https://apps-primadev.netlify.app/.netlify/functions/webhook
